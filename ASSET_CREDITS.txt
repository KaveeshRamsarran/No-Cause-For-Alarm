Original project assets
Historical 1.0 character portrait mesh (superseded by City People): generated in Blender by Tools/create_portrait.py; source SourceAssets/Portrait.blend.
Historical 1.0 face atlas (not used by the current cast): generated using the built-in OpenAI image-generation tool for this project, with twelve original fictional identities. Assets/Resources/Characters/FaceAtlas.png. Prompt and integration notes: Documentation/ART_DIRECTION.md. No reference-game face was supplied or copied.
Campus layout and collision, character assembly and animation blending, creature deformation, lighter, effects and UI: project code. Current building surfaces and characters use the credited imported packs.
Original ambience, drone and fallback sound effects: Tools/generate_audio.py. Deterministic synthesized PCM. Current footsteps use the separately credited owner-supplied recording.
PA voice: original written dialogue rendered with the installed Windows System.Speech synthesizer. No actor recording or external voice clone.
Story, dialogue, evidence and institution: original fictional content created for this project.
